# Project policy

**Contributions and issue reports are closed for now.** Jira Peek is a personal
project developed with AI assistance. Collaboration, pull requests, bug reports,
feature requests, and support requests are not being accepted. Please do not
submit them through issues, discussions, pull requests, or personal messages.
Submissions may be closed without review. No support, fixes, response times,
or release schedule are promised. This policy will be updated if intake reopens.

You can use and adapt the code under the existing [MIT License](LICENSE).
Use this experimental software with caution; review the [README](README.md)
and [security policy](SECURITY.md) before connecting an account.

Private vulnerability reports are the only reporting exception; follow
[SECURITY.md](SECURITY.md#reporting-a-vulnerability). That channel is for security
concerns only and does not provide general support or a guaranteed response.

For independent local development, follow [AGENTS.md](AGENTS.md) and the checks
in [RELEASING.md](RELEASING.md). Use entirely fictional data in anything shared.
Never publish real Jira records, credentials, local configuration, terminal
output or caches, even with identifiers renamed or blurred.
